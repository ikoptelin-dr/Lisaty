Пропионовокислые бактерии: что известно о виде

Ниже — свойства вида и отдельных штаммов в культуре. Это не свойства лизата: что из этого сохраняется в продукте, показывает только измерение.

  • Главный конечный продукт брожения — пропионовая кислота (цикл Вуда — Веркмана)[7]
  • P. freudenreichii образует короткоцепочечные жирные кислоты (пропионовую и уксусную) и витамин B12[8]
  • Вид способен синтезировать биологически активную форму витамина B12[8]
  • Микробиологический метод дал результаты на 20–40 % выше UHPLC — из-за неактивных для человека аналогов (псевдовитамин B12)[9]
  • Бифидогенный стимулятор роста из культуральной жидкости штамма ET-3 идентифицирован как 1,4-дигидрокси-2-нафтойная кислота (DHNA); около 10 мг/л[10]
  • Многие свойства вида сильно зависят от штамма[7]
  • Все виды из состава лизатов, включая Propionibacterium freudenreichii, есть в списке QPS EFSA (17.09.2026) — при условии, что у штаммов нет приобретённых генов устойчивости к клинически значимым антимикробным препаратам[11]

Литература о видах и лизатах, данные этого продукта и разрешённые формулировки этикетки — разные вещи. Мы их не смешиваем.

Литература

О видах и понятиях. Не о нашем продукте.

  • ISAPP (2021): постбиотик — «препарат неживых микроорганизмов и/или их компонентов, который приносит пользу здоровью хозяина»[12]
  • По ISAPP, такой препарат должен содержать инактивированные клетки или их компоненты — с метаболитами или без них[12]
  • Определение ISAPP оспаривается: группа авторов опубликовала возражение «Postbiotics — when simplification fails to clarify»[13]

Данные о лекарственных лизатах (препаратах) на пищевое сырьё не переносятся.

Согласование: каждая цифра под контролем директора по науке

  1. У каждой цифры есть id в реестре, класс данных и источник с дословной цитатой.
  2. Сборка находит цитату в файле-оригинале. Не нашла — страница не собирается.
  3. Директор назначает уровень раскрытия: О — открыто, З — по запросу, NDA — под соглашение.
  4. Чистовая сборка не пропускает ни одного синтетического значения.
  5. Без подписи директора по науке материал не выходит.
