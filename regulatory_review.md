# Сомнительные формулировки — для специалиста по регистрации

Ничего из этого списка сейчас нет на странице как утверждения о пользе. Но формулировки
либо уже стоят в тексте, либо почти наверняка понадобятся после получения документов.
Нужно решение специалиста по ТР ТС 021/2011, ТР ТС 022/2011 и, для БАД, по требованиям
к их регистрации.

| № | Где | Формулировка | Вопрос к специалисту |
|---|---|---|---|
| R-1 | `content.yaml` → limitations | «Лизат — это разрушенные клетки бактерий. Если вашему продукту нужны живые культуры… лизат эту задачу не решает» | Корректно ли такое определение для B2B-материала, и не подразумевает ли оно подтверждённую инактивацию (до получения G-10)? |
| R-2 | `content.yaml` → limitations | «Такое сырьё не подойдёт для линеек без молока и веганских» | Корректно ли так писать до декларации аллергенов (G-07)? Как писать про лактозу, если она есть? |
| R-3 | `claims.yaml` C-USE-01 | «Назначение: пищевая промышленность и производство БАД» | Можно ли писать так или только дословно из области применения ТУ и СГР/декларации? |
| R-4 | `claims.yaml` C-ALLERG-01 | «Содержит молоко (аллерген, указывается на маркировке)» | Правильная формулировка для B2B-спецификации по ТР ТС 022/2011 |
| R-5 | Торговые названия | «БифиЛиз», «ЛактоЛиз», «ПропиоЛиз» | Можно ли производителю БАД упоминать название сырья на своей этикетке, и есть ли регистрация товарных знаков (свидетельство — не секрет) |
| R-6 | Не используется | «пробиотик», «постбиотик», «метабиотик», «иммунобиотик» | Применимы ли эти термины к лизату в материалах для B2B и на этикетке готового БАД? Линтер сейчас их блокирует |
| R-7 | Не используется | «для иммунитета», «для микрофлоры», «поддерживает пищеварение» и любые функциональные заявления | Допустимы ли в B2B-материале о сырье, если они есть в СГР готового продукта клиента? Линтер сейчас блокирует |
| R-8 | `claims.yaml` C-LAK-03, C-PRO-03 | Устаревшие названия видов (L. fermentum, L. bulgaricus, P. shermanii) | Какое название использовать в спецификации и на этикетке: из СГР или современное? (G-04) |
| R-9 | `claims.yaml` C-INACT-01 | «Отсутствие жизнеспособных клеток» | Какая формулировка допустима, если в ТУ показатель нормируется иначе |
| R-10 | Будущие данные | Количество лизата на дозу (C-COMP-01, C-DOSE-01) | Как корректно выражать «дозу» для неживого сырья — по сухому веществу, по исходной клеточной массе? |

После решения: разрешённую формулировку внесите в `claims.yaml` с полем `reg_review: approved`.
Без этого поля сборка отклонит любое утверждение, где линтер видит слова о пользе.
