# inputs/ — первичные документы завода

На 11.11.2026 папка пуста: ни одного документа не получено.
Положите сюда файлы и укажите их в `claims.yaml` (поле `source.file` и `source.page`).
Сборка для рассылки проверяет, что каждый файл-источник реально лежит в этой папке.

Рекомендуемые имена (не обязательно):

- `spec_bifiliz.pdf`, `spec_laktoliz.pdf`, `spec_propioliz.pdf` — спецификации / ТУ
- `coa_<продукт>_<партия>.pdf` — сертификаты анализа партий (лучше 3 последние партии)
- `sgr_<продукт>.pdf` или `decl_<продукт>.pdf` — СГР / декларации ЕАЭС
- `cert_<GMP|ISO22000|HACCP>.pdf` — сертификаты с областью действия
- `kp_<дата>.pdf` — коммерческое предложение завода
- `questionnaire_answers.pdf` — ответы завода на опросник (gaps.md)
- `supplier_qualification_<компания>.pdf` — анкеты квалификации от производителей БАД
- `correspondence_<дистрибьютор>.eml|.pdf` — переписка с дистрибьюторами
